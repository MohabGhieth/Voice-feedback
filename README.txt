MG RESALE — GitHub Pages Voice Mode

1) Create a new GitHub repository, for example:
   mg-resale-voice

2) Upload these files to the repository root:
   - index.html
   - .nojekyll

3) Open:
   Repository -> Settings -> Pages

4) Under Build and deployment:
   Source = Deploy from a branch
   Branch = main
   Folder = /(root)
   Save

5) GitHub will publish the page at:
   https://YOUR-USERNAME.github.io/mg-resale-voice/

6) Send me that final github.io URL.
   I will give you the final Apps Script Index.html with the URL already connected.

Important:
- Do not put Gemini API keys, Google Sheet IDs, or other secrets in this GitHub repository.
- The GitHub page is only the microphone / speech interface.
- The Google Apps Script backend continues to do the CRM processing and Gemini work.
